Section 1: English Content
---------------------------

Lantern is a lightweight, self-hosted full-text search platform for Windows and intranet environments.

It is built on:
- ASP.NET Core and Blazor for the web interface
- Meilisearch Community Edition for full-text indexing and search
- Toxy for document text extraction
- .NET 10 LTS as the runtime
